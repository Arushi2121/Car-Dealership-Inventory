# Images

Body-style photos used across the app. Each car shows the photo for its category unless an admin sets its own image URL.

Expected files:

- `hero.jpg` (landing hero)
- `sedan.jpg`
- `suv.jpg`
- `hatchback.jpg`
- `coupe.jpg`
- `convertible.jpg`
- `pickup.jpg`
- `van.jpg`

Credits for every image (photographer, source link and licence) go in `CREDITS.md` in this folder.
